# 智能巡检车 APP · 项目分层验收方案

> 适用范围：第一阶段（TCP 直连模拟）全部代码。
> 验收原则：**自底向上**，每层通过后再进入下一层；下层问题不留给上层排查。

## 分层总览与依赖关系

```
第五层  可视化层      topview.html          （依赖第三层）
第四层  APP 交互层    Index.ets             （依赖第二层）
第三层  小车模拟层    car_server.py 运动模拟  （依赖第一层）
第二层  网络连接层    CarTcpClient.ets + TCP 服务端 （依赖第一层）
第一层  通信协议层    Protocol.ets + 服务端解析约定
```

验收顺序：第一层 → 第二层 → 第三层 → 第四层 → 第五层 → 总验收。

---

## 第一层：通信协议层

**内容**：`model/Protocol.ets` 的消息格式定义与服务端解析约定是否一致。

| # | 验收点 | 预期结果 |
|---|--------|----------|
| 1.1 | move 指令格式 | `{"type":"cmd","action":"move","vx":x,"vy":y}`，分量四舍五入到 2 位小数 |
| 1.2 | stop / ping 指令格式 | 与文档一致，均以 `\n` 结尾 |
| 1.3 | 粘包处理 | 三条消息一次发送，服务端仍能逐条解析 |
| 1.4 | 拆包处理 | 半条消息到达不误解析，剩余部分与后续数据拼接后正常 |

**验收方式**：`python tools/acceptance_test.py 1`（自动）

## 第二层：网络连接层

**内容**：`net/CarTcpClient.ets` 与服务端 TCP 监听/状态广播的连接质量。

| # | 验收点 | 预期结果 |
|---|--------|----------|
| 2.1 | 建立连接 | APP 点"连接"后日志显示"已连接到模拟小车" |
| 2.2 | 心跳保活 | 连接静置 10 秒以上不掉线（服务端每 5 秒收到 ping） |
| 2.3 | 状态广播 | APP 连接期间持续收到 state（5Hz，每秒约 5 条） |
| 2.4 | 断线感知 | 服务端 Ctrl+C 后 APP 日志显示"连接断开：连接异常/对端关闭" |
| 2.5 | 重复连接 | 断开后再次点"连接"能成功（无残留 socket 冲突） |

**验收方式**：`python tools/acceptance_test.py 2`（自动，约 15 秒）+ 模拟器手动复验 2.1/2.4/2.5

## 第三层：小车模拟层

**内容**：`car_server.py` 中 CarSim 运动模型与安全措施。

| # | 验收点 | 预期结果 |
|---|--------|----------|
| 3.1 | 匀速直线 | move (0,1) 持续 1 秒，y 增量 ≈ 1.5m（MAX_SPEED），theta = 0° |
| 3.2 | 方向映射 | move (0.7,0.7) 时 theta ≈ 45°，速度 ≈ 1.5 × 0.99 ≈ 1.49 |
| 3.3 | 摇杆限幅 | move (1,1) 时速度不超过 MAX_SPEED（矢量归一化） |
| 3.4 | 停车 | stop 后 speed = 0，位置不再变化 |
| 3.5 | 电量消耗 | 移动时 battery 下降，静止时不变 |
| 3.6 | 断连安全 | TCP 客户端异常断开（不发 stop）后，小车 1 秒内自动停车 |
| 3.7 | HTTP 数据源 | GET /state 与 TCP 广播内容一致（同一 CarSim 快照） |
| 3.8 | 全角度朝向 | 按角度 210° 行驶，theta ≈ 210° |
| 3.9 | 全角度位移 | 按角度 315° 行驶，位移为西北方向（Δx<0，Δy>0） |

**验收方式**：`python tools/acceptance_test.py 3`（自动，约 8 秒）

## 总验收：全链路联调

一条完整演示流程（可录屏作为最终验收材料）：

1. 启动 `python tools/car_server.py`，浏览器打开俯视图；
2. APP 连接 → 按 ↑ 前进 2 秒 → 按 → 右转 1 秒 → 点 ■ 急停；
3. 同时确认：① APP 状态面板数值连续变化；② 俯视图同步画出折线轨迹；
4. APP 点"断开" → 俯视图小车 1 秒内停止（断连自动停车生效）。

**通过标准**：4 个步骤全部符合预期，全程无崩溃、无协议报错日志。
