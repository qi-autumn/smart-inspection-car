1. 通用约定

项值
Base URLhttp://<后端IP>:8000（本机调试 http://127.0.0.1:8000）
请求/响应格式JSON（Content-Type: application/json）
统一响应包络{ "ok": true, ...数据 } 成功；{ "ok": false, "error": "原因" } 失败。HTTP 状态码同时标注（200/400/403/404/502）
管理接口鉴权请求头 X-Auth-Token: <token>（由 POST /admin/login 签发；内存态，后端重启即失效需重登）
坐标约定x 向东增大、y 向北增大，单位米；heading（theta）0=正北、顺时针增大（90=正东）
device_id云端全名 {product_id}_car_00N，如 YOUR_PRODUCT_ID_car_001；/command 支持传短名 car_001 自动解析
时间参数Unix 秒 或 YYYY-MM-DD HH:MM[:SS]（本地时区）

2. REST · 查询类接口

GET/health

健康检查。响应：{"ok":true,"total":4,"online":1,"local_fast":true}

local_fast 字段：后端是否启用"本地高速旁路"。启用时后端以 10Hz 直读模拟器进程内存状态（本机 :8081~8085/state）喂给缓存和 WS，不产生任何云端消息，位置更新从 5s 一跳变为 0.1s 连续刷新；设环境变量 V3_LOCAL_FAST=0 可关闭（第⑧步真车接入后应关闭）。轨迹库仍只记真实影子观测，不受影响。
GET/devices

注册表全部车辆（静态信息 + 实时状态）。

{
  "ok": true,
  "devices": [
    { "device_id": "…_car_001", "name": "1号巡检车", "color": "#3aa55d",
      "frozen": false, "online": true,
      "x": 10.2, "y": 5.0, "heading": 90.0, "speed": 60.0,
      "battery": 98.5, "time": "2026-11-08 08:30:00" }
  ]
}
GET/status?device_id=…_car_001

单车状态（读缓存）。字段同上单个元素。

GET/fleet/status

全队状态批量（APP 主用，800ms 轮询）。

{
  "ok": true,
  "cars": [
    { "device_id": "…_car_001", "name": "1号巡检车", "color": "#3aa55d",
      "online": true, "x": 10.2, "y": 5.0, "heading": 90.0,
      "speed": 60.0, "battery": 98.5, "time": "…" },
    { "device_id": "…_car_002", "online": false, "x": null, "y": null,
      "heading": null, "speed": 0, "battery": null, "time": null }
  ]
}

离线车：x/y/heading/battery 为 null，speed 为 0。前端按 online 判断渲染。

GET/track?device_id=…&from=…&to=…
参数：device_id 必填；from/to 可选，缺省最近 24 小时。
{
  "ok": true,
  "device_id": "…_car_001",
  "points": [
    { "x": 10.2, "y": 5.0, "theta": 90.0, "speed": 60.0,
      "battery": 98.5, "t": "2026-11-08 08:30:00" }
  ]
}

时间升序；t 为本地时间字符串（APP 解析：Date.parse(t.replace(' ','T'))）。仅"真实影子观测且位置/状态变化"的点会入库。

GET/audit/recent

最近命令审计（JSONL 尾部）。

3. REST · 控制接口

POST/command
字段说明
device_id必填。全名或短名
cmd必填。FORWARD / BACK / LEFT / RIGHT / STOP / MOVE
speed0–100（%）。FORWARD/BACK/LEFT/RIGHT/MOVE 必带；STOP 不带
angle仅 MOVE：0–360，航向角（0=北，顺时针）
请求
POST /command
{ "device_id": "car_001", "cmd": "MOVE", "angle": 90, "speed": 70 }

换算（后端完成）
vx = sin(90°) × 70/100 = 0.70   （向东）
vy = cos(90°) × 70/100 = 0.00   （向北分量）

响应 200
{ "ok": true, "device_id": "…_car_001",
  "command_id": "b67a…", "executed": true, "response_name": "MOVE" }
语义说明（重要）：拉模式下应用侧收不到设备 MQTT 回执，当前返回的 executed:true 表示云平台已受理（设备在线时立即送达）。真实的"已执行"确认来自设备随后的属性上报（命令后 ≤2s 事件补报），前端通过乐观回显+影子校准呈现。
错误：400 参数缺失/非法、未注册；403 设备已冻结；502 华为云 API 调用失败（含设备离线时命令仍可投递——命令队列会暂存，设备上线后收到）。

4. WebSocket /ws 实时广播

连接 ws://<后端IP>:8000/ws。服务端单向推送，客户端无需发送任何消息。

推送节奏说明
事件驱动任何 /command 受理（乐观回显）→ 立即推一帧（命令→画面 ≈0.33s）
兜底周期每 0.5s 一帧（缓存未变时内容相同）
帧格式（JSON 文本帧）
{ "type": "fleet_state",
  "ts": 1699423200,
  "cars": [
    { "device_id": "…_car_001", "name": "1号巡检车", "color": "#3aa55d",
      "online": true, "x": 10.2, "y": 5.0, "heading": 90.0,
      "speed": 60.0, "battery": 98.5, "time": "…" }
  ]
}

帧语义契约（页面端航位推算依赖）：x/y 变化 = 真实位置修复；仅 heading/speed 变化 = 命令回显。客户端据此决定"对齐观测"还是"换向外推"。

5. REST · 管理接口 /admin/*（X-Auth-Token 鉴权）

POST/admin/login
请求  { "username": "admin", "password": "admin123" }
响应  { "ok": true, "token": "8df7f131…" }    注意字段是 username（非 user）
GET/admin/overview

总览统计：车辆总数/在线数/冻结数/今日命令数等。

GET/admin/devices

注册表 + 实时状态（管理页签数据源）。响应结构同 /devices，另含 spawn/http_port。

POST/admin/devices注册新车
请求  { "node_id": "car_006", "name": "6号巡检车" }
响应  { "ok": true, "device_id": "…_car_006", "secret": "YOUR_CREDENTIAL",
        "color": "#16a085", "spawn": [0, 18], "http_port": 8086 }
流程：先 DeleteDevice 清云端可能残留 → AddDevice 建档 → devices.json 追加（自动分配颜色/出生点/调试端口 8081+N）。
POST/admin/devices/<did>/freeze冻结/解冻
请求  { "frozen": true }     响应  { "ok": true, "frozen": true }

冻结后对该设备的 /command 一律 403，设备连接本身不受影响。

DELETE/admin/devices/<did>注销设备
请求  { "confirm": true }
流程  停模拟器进程 → 云端 DeleteDevice → devices.json 移除
约束  车队至少保留一台，全删返回 400
GET/admin/cloud/devices云端对账
{ "ok": true,
  "cloud": [
    { "device_id": "…_car_001", "node_id": "car_001", "status": "ONLINE",
      "in_registry": true,  "sync": "两边一致" },
    { "device_id": "…_car_004", "node_id": "car_004", "status": "OFFLINE",
      "in_registry": false, "sync": "云端残留" } ],
  "local_only": [] }

实现注意：ListDevices 的 limit 上限 50（传 100 报 400），按 product_id 客户端过滤。

DELETE/admin/cloud/<did>删除云端残留
POST/admin/devices/<did>/start上线POST…/stop下线

后端在本机拉起/终止该车的模拟器进程（start 前自动清理僵进程；stop 按命令行特征 car_mqtt_client.py --device <node> 匹配全部实例）。上线约 3s 后云端状态翻为 ONLINE。

GET/admin/commands

命令历史（分页字段 limit/offset）。

GET/monitor/view · /admin/view · /track/view · /console/view

展示页路由（动态返回 HTML，无需重启即可更新）。

6. 设备 MQTT 协议（模拟器 ↔ 云端，真车同款合同）

项值
接入地址iot-mqtts.cn-north-4.myhuaweicloud.com:8883（TLS）
认证平台生成的 ClientID / Username / Password 三元组（密钥即 devices.json 的 secret）

6.1 上行 · 属性上报（car_status 服务）

Topic  $oc/devices/{device_id}/sys/properties/report
{
  "services": [{
    "service_id": "car_status",
    "properties": {
      "x": 10.2,        // 东向坐标，米
      "y": 5.0,         // 北向坐标，米
      "theta": 90.0,    // 朝向角，0=正北顺时针
      "speed": 60.0,    // 0-100
      "battery": 98.5   // 0-100
    }
  ]
}
上报时机间隔说明
行驶中5 s路线图硬约束（IoTDA 免费单元约 1 万条/日）
静止60 s保活报平安
命令执行后立即（限流 2s）事件补报，缩短命令可见延迟

6.2 下行 · 命令（car_control 服务）

订阅 Topic  $oc/devices/{device_id}/sys/commands/#
收到的消息体
{ "paras": { "vx": 0.7, "vy": 0.0 },   // move：车体坐标速度矢量，vx右/vy前
  "service_id": "car_control",
  "command_name": "move" }              // 或 stop（paras 为空）
回执 Topic  …/sys/commands/request_id={rid}（request_id 从命令 topic 提取）
易错点：命令挂 car_control，属性挂 car_status，两个 service_id 不可混用。

7. 后端 ↔ 云端 SDK 调用（huaweicloudsdkiotda v5）

方法用途调用时机已踩坑
ShowDevice查单台在线状态poll_loop 每 2sListDevices 过滤参数不生效→必须逐台查；status 平铺在 resp.status
ShowDeviceShadow读影子属性poll_loop 每 2s属性在 resp.shadow[].reported.properties；数值是 Decimal
CreateCommand下发 move/stopPOST /command命令体类是 DeviceCommandRequest（非文档 CommandBody）
AddDevice / DeleteDevice注册 / 注销admin 注册/删除注册前先 DeleteDevice 清残留，否则"已存在"
ListDevices云端对账GET /admin/cloud/deviceslimit 上限 50

鉴权：BasicCredentials(AK, SK, project_id) + derived predicate；区域 Region(region_id, endpoint)，配置在 server/cloud_config.json。

8. 错误码与排错

HTTP含义常见原因
400参数错误 / 未注册 / 车队至少留一台缺 device_id、cmd 非法、speed 越界、设备不在注册表
401/403未登录 / 已冻结X-Auth-Token 缺失或失效（重启后端后要重登）；frozen=true
404资源不存在did 拼错
502华为云 API 失败AK/SK 失效、配额耗尽、设备名不存在

快速排查顺序

①车在线吗（/fleet/status）→ ②被冻结吗 → ③server/commands.log 最后几行的 result → ④后端控制台报错 → ⑤模拟器黑窗是否被关闭（关窗=下线）。
